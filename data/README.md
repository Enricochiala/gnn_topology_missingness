# Bundled datasets

The six files in `temporal/prepared_v2/` contain the prepared arrays actually
used in the forecasting experiments. Their `.json` sidecars record preprocessing,
observation-mask semantics, graph size, timestamp range and chronological split
bounds. They are not newly downloaded or reprocessed versions. Data manifests
contain relative paths only. `temporal/SOURCES.json` records the original public
source URLs and raw-file hashes for the five real temporal datasets; GraphMSO
is synthetic, with its generator retained in `temporal_data.py`.

A temporal `.npz` contains: `values[T,N,C]`, `observed[T,N,C]`, `timestamps[T]`,
`edge_index[2,E]`, `edge_weight[E]`, `channels[C]`, `node_ids[N]` and `pe[N,16]`.
No account names, machine identifiers, credentials or run logs are bundled.
Sensor IDs and timestamps are dataset fields; they preserve the graph and time
alignment. They do not identify the code authors.

Observation masks follow the forecasting benchmark, which is not always the
same as sensor failure. PV-US excludes nighttime zeros and one broken sensor;
METR-LA and PEMS-BAY treat zero speeds as missing. EngRAD zero radiation is an
observed value. PEMS-BAY has a small original missing fraction that remains
masked before additional RT/UMCAR injection. Read the sidecars for details.
No additional missingness is injected into AQI, PV-US or METR-LA.

`tadpole.pt` contains a PyG Data object with only numeric features `x[555,15]`,
class labels `y[555]`, graph edges `edge_index[2,8325]`, topology-derived PE
`pe[555,8]`, and the class count (3). Feature values, labels and edges are copied
from the original available graph artifact; unused auxiliary fields and old
split masks are removed. Splits are generated by the original evaluator.
No patient identifiers or free-text fields are included. This is the processed
classification graph, not the raw clinical database. Only load trusted `.pt`
files. Dataset access and redistribution terms remain those of the original
providers; this code archive does not replace them.

PE is frozen in the supplied data. The classification launcher recomputes it
only when explicitly requested with `--recompute-pe`. Temporal runs use the
supplied PE directly. Hashes and dimensions are recorded in `MANIFEST.json`;
run `python verify_data.py` from the repository root to check integrity.
