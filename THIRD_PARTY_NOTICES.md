# Third-party notices

Retained third-party implementations include GCNmf, Feature Propagation, PCFI
and FISF. Their source copyright notices and the license texts supplied with
the implementation are retained in `licenses/` and in source headers.
Dependencies retain their own licenses. This archive does not assign a new
blanket license to the combined code or change dataset access terms.

`graph_utils.py` contains the adjacency-normalization helpers used by Feature
Propagation, under their original Apache-2.0 notice. It contains no model.
The release removes project-specific author identities and machine metadata;
third-party copyright holders are not anonymized.
